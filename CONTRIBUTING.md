# Contributing

Thanks for helping make software supply chains safer.

1. Open an issue describing the bug or feature.
2. Fork and create a focused branch.
3. Add tests or lockfile fixtures for each parser and detection change.
4. Run `npm test` and `npm run check`.
5. Submit a pull request describing behavior and security trade-offs.

Please don't post malware samples or sensitive credentials in issues. Do not add runtime dependencies without a strong security and maintenance justification.
